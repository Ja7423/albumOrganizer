# Spec：「資料夾」tab

| 項目 | 內容 |
|------|------|
| Tab 位置 | 第 2 個，圖示 `folder`，標籤「資料夾」 |
| 畫面 | 根：`Views/Library/FoldersScreen.swift`；下一層：`ShotGridScreen(route:)` |
| 導航 | `NavigationStack(path: $ui.folderPath)`，route 為 `.processing` / `.unsorted` / `.folder(UUID)`；系統導航列隱藏，保留左緣滑動返回 |
| 相關領域規則 | `Library` 的 Folders 區段、`Library.deleteFolder`、`Library+Classification` |
| 共用元件 | 詳細頁、批次列、sheet、命名對話框 → [shared-detail-and-sheets.md](shared-detail-and-sheets.md) |

## 1. 目的

依「類別」瀏覽截圖。資料夾就是類別：App 內建 12 個類別資料夾，自動分類會把截圖直接放進去；使用者也能自建、改名、刪除。**一張截圖最多只在一個資料夾**，沒有資料夾就是「未分類」。

## 2. 資料夾的種類

| 種類 | 來源 | 可改名 | 可刪除 | 自動分類會放入 |
|------|------|------|------|------|
| 處理中（虛擬） | `placement == .pending` 的截圖 | 否 | 否 | — |
| 未分類（虛擬） | `folderID == nil` 且非處理中 | 否 | 否 | 判斷不出來時 |
| 內建資料夾 | `BuiltInCategory`：收據、票券、對話、社群貼文、文章、程式碼、地點、食譜、優惠、帳號資訊、行程、筆記 | 是（只改顯示名稱，分類 key 不變） | 是（記住已刪除，不再建回、不再分類進去） | 是 |
| 自建資料夾 | 使用者新增 | 是 | 是 | 否（要等 kNN 層） |

內建資料夾在 `Library` 初始化時補齊：沒有且沒被刪除過的類別會自動建立。

## 3. 根畫面：資料夾列表

### 3.1 版面

```
N 個資料夾                [＋ 新增]
資料夾
┌ 部分權限提示（有限存取時）┐
[⌛] 處理中        12 張   ›     ← 只有處理中 > 0 時顯示
[▭] 未分類         30 張   ›
[縮圖] 收據        8 張    ›
[縮圖] 對話        5 張    ›
 …
[📁] 食譜          0 張    ›     ← 空的內建資料夾，50% 透明
```

- Kicker：`N 個資料夾`（只算真實資料夾，不含處理中／未分類）。
- 「新增」→ 命名對話框 `.newFolder(moveAfter: false)`。
- 每列：52×52 封面（該資料夾第一張＝最新的截圖，靠上裁切；空的顯示圖示）、名稱（單行）、`N 張`、›。

### 3.2 排序

1. 處理中（有才顯示）
2. 未分類（永遠顯示，即使 0 張）
3. 真實資料夾：`library.foldersEmptyLast`——有截圖的在前、空的在後，各自維持儲存順序（內建依類別宣告順序，自建依建立順序附在後面）。

空的**內建**資料夾以 50% 透明度顯示（仍可點進去、仍可當移動目標）；空的自建資料夾正常顯示。

### 3.3 長按選單（只有真實資料夾）

| 項目 | 行為 |
|------|------|
| 重新命名 | 命名對話框 `.renameFolder(id)`，預填目前名稱。名稱與其他資料夾重複時拒絕並 toast「已經有同名的資料夾」 |
| 刪除資料夾（destructive） | **立即刪除，沒有確認**。toast「已刪除資料夾「X」，自動分類的截圖會重新分類」 |

刪除資料夾的規則（`Library.deleteFolder`）：

- 裡面**使用者放入**的截圖 → 移到未分類，維持鎖定。
- 裡面**自動分類**的截圖 → 回到處理中，重新跑分類；被刪掉的內建類別會被排除，所以會落到其他類別或未分類。
- 刪的是內建資料夾 → 類別記入 `deletedBuiltIns`，之後不再自動建回、也不再分類進去。
- 刪除後 `store.deleteFolder` 會啟動處理佇列。

## 4. 下一層：資料夾內的 grid

點任一列 push `ShotGridScreen(route:)`，與截圖 tab 的 grid 相同（3 欄、選取模式、BatchBar、點擊開詳細頁，見 [tab-screenshots.md §2.3–§3](tab-screenshots.md)），差異如下：

| 項目 | 資料夾 grid |
|------|------|
| 返回 | 左上「‹ 資料夾」按鈕（同時結束選取模式），或左緣滑動返回 |
| 標題 | 處理中 →「處理中」；未分類 →「未分類」；資料夾 → 目前名稱（改名後即時更新） |
| Scope | `.processing` / `.unsorted` / `.folder(id)` |
| Chip 列、部分權限提示 | 不顯示 |
| 詳細頁翻頁範圍 | 這個資料夾目前的截圖清單（開啟時的快照） |
| 空狀態 | 「這裡還沒有截圖。到「截圖」選取後，用「移到資料夾」或「標籤」整理進來。」 |

注意：

- 在資料夾 grid 裡批次「移到資料夾」到別處，截圖會立即從這個 grid 消失。
- 在「處理中」grid 裡，截圖處理完成後也會即時離開這個 grid。
- 若資料夾在 push 狀態下被刪除，標題會回退成「未分類」、內容變空（目前只能從根畫面長按刪除，所以實務上不會發生）。

## 5. 導航狀態

- 點任何 tab（`ui.selectTab`）都會清空 `folderPath` 與選取模式：切到別的 tab 再回來，或在資料夾 grid 裡再點一次「資料夾」tab，都會回到根畫面。

## 6. 截圖如何進出資料夾

| 方式 | 結果 placement |
|------|------|
| 規則層命中內建類別 | `.auto(source: .rule, version)` |
| 規則層判斷不出 | `.auto(source: nil)`，進未分類，之後在背景用 Apple Intelligence 補判 |
| 補判命中內建類別 | `.auto(source: .llm, isRefined: true)`，從未分類移到資料夾 |
| 補判判斷不出（或裝置不支援） | 留在未分類；判斷不出時標記 `isRefined: true`，不支援時下次再試 |
| 批次或詳細頁「移到資料夾」（包含移到未分類） | `.user`，永不再被自動移動 |
| 分類器版本更新 | 舊版本的自動結果回到處理中重做；`.user` 不動 |
| 自動分類或補判正在跑時使用者先手動移動 | 手動結果優先，分類結果被丟棄 |

完整的分類規則見 [classification.md](../classification.md)。

## 7. 驗收清單

- [ ] 處理中為 0 時不顯示「處理中」列；未分類即使 0 張也顯示。
- [ ] 有截圖的資料夾排在空資料夾前面；空的內建資料夾半透明，空的自建資料夾不透明。
- [ ] 新增同名資料夾不會產生重複資料夾。
- [ ] 改名成另一個資料夾的名稱會被拒絕，對話框保留。
- [ ] 刪除內建「收據」後：原本自動分類進去的截圖重新分類且不會再進收據；手動放入的進未分類；重啟 App 後收據不會被建回。
- [ ] 處理中與未分類的列沒有長按選單。
- [ ] 進入資料夾 grid → 切到其他 tab → 回來時在資料夾列表根畫面。
- [ ] 從資料夾 grid 開詳細頁，把目前這張移到別的資料夾後，仍可在詳細頁繼續左右翻。
