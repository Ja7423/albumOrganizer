# Spec：「搜尋」tab

| 項目 | 內容 |
|------|------|
| Tab 位置 | 第 4 個，圖示 `magnifyingglass`，標籤「搜尋」 |
| 畫面 | `Views/Library/SearchScreen.swift` |
| 導航 | 沒有 NavigationStack；點結果直接開詳細頁 |
| 搜尋邏輯 | `Packages/ScreenshotKit/Sources/ScreenshotKit/Search.swift` → `Library.search(_:)` |
| 共用元件 | 詳細頁 → [shared-detail-and-sheets.md §1](shared-detail-and-sheets.md#1-詳細頁shotdetailscreen) |

## 1. 目的

每張截圖匯入時都在裝置上辨識過文字，所以可以直接用「圖裡的字」找截圖，例如密碼、地址、訂單編號。也能用標籤名稱或截圖標題找。

## 2. 版面

```
搜尋
┌🔍 圖中文字或標籤        ✕┐
│                          │
試試搜尋                       ← 查詢為空時
[密碼][訂單編號][地址][發票]
每張截圖匯入時都會辨識文字…

找到 N 張                      ← 有查詢時
─────────────────────────
[縮圖] 標題                    ← ResultRow
       10月5日 18:42 · #發票
       …訂單編號：【A12345】678
```

### 2.1 搜尋欄

- Placeholder「圖中文字或標籤」，鍵盤 return 鍵為「搜尋」，關閉自動修正與自動大寫。
- 有輸入時右側出現 ✕「清除」按鈕，清空查詢（不收起鍵盤）。
- focus 時邊框變 accent。
- **即時搜尋**：每次輸入都重新計算，不需要按搜尋。
- 捲動結果時互動式收起鍵盤。
- 查詢字串是畫面 `@State`：切換 tab 後回來會清空。

### 2.2 查詢為空（去掉前後空白後）

- 「試試搜尋」與範例 chip：密碼、訂單編號、地址、發票。點 chip 把文字填入搜尋欄。
- 說明文字：「每張截圖匯入時都會辨識文字，所以可以直接搜尋圖片裡的密碼、地址、訂單編號。」

### 2.3 有查詢

- Kicker「找到 N 張」＋分隔線。
- 結果列（`ResultRow`）：
  - 52×72 縮圖（靠上裁切）
  - 標題（`shot.title`，單行）
  - Meta：日期（`ShotFormat.shortDate`）與我的標籤 `#tag`，以「 · 」串接，單行
  - 片段：前文 + **高亮的命中字**（accent200 底、accent900 字）+ 後文，最多 3 行
- 沒有結果：「沒有截圖包含「查詢」。」

## 3. 搜尋規則（`Library.search`）

1. 查詢去掉前後空白，空字串回傳空陣列。
2. 比對選項：**不分大小寫、不分全形半形**（`.caseInsensitive`、`.widthInsensitive`）；子字串比對，不做斷詞、不做模糊比對。
3. 每張截圖依序檢查：
   1. **辨識文字**：依文字行順序（由上到下、同一列由左到右），找到第一個包含查詢的行就停止。
      - 片段 = 該行切成前文／命中／後文；前文超過 12 字時只保留最後 12 字並加「…」。
   2. 若沒有文字命中，再檢查 **我的標籤、自動標籤的顯示名稱（例如「含地址」）、標題**。
      - 命中時片段是第一行辨識文字，**沒有高亮**。
   3. 都沒命中就不列入。
4. 每張截圖最多一筆結果。
5. 結果順序 = Library 順序（截圖時間新到舊），不依相關度排序。
6. 搜尋範圍是 App 內所有截圖，包含處理中的（已辨識完、還在等分類的可以用文字命中；尚未辨識的沒有文字可比對）；從 App 移除的截圖不在範圍內。

## 4. 點擊結果

- 收起鍵盤，`ui.openDetail(id, in: 所有結果的 id)`：打開詳細頁，左右翻頁的順序就是搜尋結果的順序。
- 詳細頁是開啟當下的快照：之後改查詢不影響已開的詳細頁。
- 搜尋 tab 沒有選取模式，底部永遠是 TabBar。

## 5. 效能備註

- 搜尋在 `body` 裡同步執行，每次 Library 變動或查詢改變都會對全部截圖的全部文字行做線性掃描。幾千張截圖以內可接受；更大的量需要索引或 debounce。

## 6. 驗收清單

- [ ] 查詢為空或只有空白時顯示範例 chip 與說明，不顯示「找到 0 張」。
- [ ] 點範例 chip「密碼」立刻出現結果。
- [ ] 查詢 `ABC` 能找到圖中寫 `abc` 或全形 `ＡＢＣ` 的截圖，且高亮原文字樣。
- [ ] 命中行前文很長時，片段開頭為「…」加最後 12 字。
- [ ] 查詢「含地址」能找到帶自動標籤「含地址」的截圖（即使圖中沒有這三個字），片段無高亮。
- [ ] 查詢我的標籤名稱能找到加了該標籤的截圖。
- [ ] 結果依截圖時間新到舊排列。
- [ ] 從結果開詳細頁，左右翻頁只在搜尋結果之間。
- [ ] 切到其他 tab 再回來，查詢已清空。
