# Spec：「標籤」tab

| 項目 | 內容 |
|------|------|
| Tab 位置 | 第 3 個，圖示 `tag`，標籤「標籤」 |
| 畫面 | 根：`Views/Library/TagsScreen.swift`；下一層：`ShotGridScreen(route:)` |
| 導航 | `NavigationStack(path: $ui.tagPath)`，route 為 `.feature(FeatureTag)` / `.tag(String)`；系統導航列隱藏，保留左緣滑動返回 |
| 相關領域規則 | `Library` 的 Tags 區段、`FeatureTag`、`FeatureDetector`、`SignalExtractor` |
| 共用元件 | 詳細頁、批次列、標籤 sheet、命名對話框 → [shared-detail-and-sheets.md](shared-detail-and-sheets.md) |

## 1. 目的

標籤是資料夾之外的第二個維度：**一張截圖可以有多個標籤**。分成兩種：

| 種類 | 來源 | 顯示 | 可全域刪除 | 可從單張移除 |
|------|------|------|------|------|
| 自動標籤（`FeatureTag`） | 分類時從辨識文字偵測 | 名稱本身，例如「含連結」 | 否 | 是（詳細頁標籤 sheet，移除後不再加回） |
| 我的標籤 | 使用者建立 | `#名稱` | 是 | 是（標籤 sheet 取消勾選） |

### 1.1 自動標籤的偵測規則

由 `SignalExtractor.extract` 算訊號，`FeatureDetector.detect` 轉成標籤（數量 > 0 就加）：

| 標籤 | 偵測方式 |
|------|------|
| 含連結 | `NSDataDetector` 的 link，或 `https?://…`、`xxx.com/.tw/.org/.io/.net/.dev/.app` |
| QR code | Vision 偵測到任一條碼／QR code |
| 含電話 | 只認明確格式：`09xx-xxx-xxx`、`(0x) xxxx-xxxx`、`+886 …`（不用 NSDataDetector，避免任意 8 位數被當電話） |
| 含日期 | `yyyy/mm/dd`（`/ . -` 分隔）或 `M月d日／號`（不認「今天」等相對字） |
| 含地址 | `NSDataDetector` 的 address，或「市／縣…區／鄉／鎮…路／街／道／巷…N號」 |

- 偵測在分類那一步一起做；重新分類時會重算，但扣掉使用者移除過的（`dismissedFeatureTags`）。
- 沒有任何截圖帶有的自動標籤不會顯示。

### 1.2 我的標籤的名稱規則

`Library.normalizedTag`：去掉前後空白、去掉開頭所有 `#`、再去一次空白。空字串不建立。名稱完全相同（區分大小寫）視為同一個標籤，不重複建立。

## 2. 根畫面：標籤列表

### 2.1 版面

```
N 個標籤              [編輯] [＋ 新增]
標籤
自動偵測（AutoLabel）
[✦] 含連結                 14  ›
[✦] QR code                 3  ›
我的標籤
[#] 發票                    8  ›
[#] 報稅                    0  ›
```

- Kicker：`N 個標籤` = 出現中的自動標籤數 + 我的標籤數。
- 「自動偵測」區：只有至少一個自動標籤出現時才顯示；依宣告順序（含連結、QR code、含電話、含日期、含地址）；圖示 sparkles。
- 「我的標籤」區：有我的標籤時才顯示小標題（前面有自動區時上方留 24pt）；依建立順序；圖示 `number`；**0 張的標籤也列出**。
- 每列右側是張數（等寬數字）與 ›。

### 2.2 Header 動作

| 按鈕 | 行為 |
|------|------|
| 「編輯」／「完成」（ghost） | 切換編輯模式。沒有我的標籤且不在編輯中時停用 |
| 「新增」（primary） | 命名對話框 `.newTag`；建立成功 toast「已建立 #X」，已存在則不重複建立 |

### 2.3 編輯模式

- 只影響「我的標籤」：每列的 › 換成垃圾桶按鈕，列本身不能點進去。
- 自動標籤列不受影響（仍可點進去、沒有刪除鈕）。
- 點垃圾桶 → `Library.deleteTag`：**立即刪除，沒有確認**；從清單與所有截圖上移除。
  - 若截圖 tab 目前 chip 正是這個標籤，chip 重設為「全部」。
  - toast「已刪除 #X」。
- 刪到沒有我的標籤時，按鈕仍顯示「完成」可離開編輯模式。
- 編輯狀態是畫面的 `@State`：切換 tab 後回來會重設為非編輯。

### 2.4 空狀態

沒有任何自動標籤也沒有我的標籤時：「還沒有標籤。按「新增」建立，或等文字辨識完成後，含連結、電話、地址等的截圖會自動加上標籤。」

## 3. 下一層：標籤內的 grid

點任一列 push `ShotGridScreen(route:)`，與截圖 tab 的 grid 相同（3 欄、選取模式、BatchBar、點擊開詳細頁，見 [tab-screenshots.md §2.3–§3](tab-screenshots.md)），差異如下：

| 項目 | 標籤 grid |
|------|------|
| 返回 | 左上「‹ 標籤」按鈕（同時結束選取模式），或左緣滑動返回 |
| 標題 | 自動標籤 → 顯示名稱（例如「含連結」）；我的標籤 →「#名稱」 |
| Scope | `.feature(tag)` / `.tag(name)` |
| Chip 列、部分權限提示 | 不顯示 |
| 詳細頁翻頁範圍 | 這個標籤目前的截圖清單（開啟時的快照） |
| 空狀態 | 「這裡還沒有截圖。到「截圖」選取後，用「移到資料夾」或「標籤」整理進來。」 |

在標籤 grid 裡用批次「標籤」sheet 取消這個標籤，截圖會立即從 grid 消失。

## 4. 截圖如何加上／拿掉標籤

| 操作 | 入口 | 規則 |
|------|------|------|
| 建立空標籤 | 本 tab「新增」 | 只建立，不加到任何截圖 |
| 加／拿掉我的標籤 | 標籤 sheet（詳細頁或批次） | 目標**全部**都有 → 全部拿掉；否則全部加上 |
| 建立並加上 | 標籤 sheet 的輸入框 | 不存在就建立，然後加到所有目標 |
| 移除單張的自動標籤 | 詳細頁標籤 sheet 的「自動偵測」區 | 只對這張有效，記在 `dismissedFeatureTags`，永不再加回 |
| 全域刪除我的標籤 | 本 tab 編輯模式 | 從清單與所有截圖移除 |

## 5. 導航狀態

- 點任何 tab（`ui.selectTab`）都會清空 `tagPath` 與選取模式：切走再回來，或在標籤 grid 裡再點一次「標籤」tab，都會回到根畫面。

## 6. 驗收清單

- [ ] 沒有任何標籤時顯示空狀態，「編輯」停用。
- [ ] 只有自動標籤時不顯示「我的標籤」小標題，「編輯」停用。
- [ ] 新增「#發票」與「發票」得到同一個標籤「發票」。
- [ ] 編輯模式下我的標籤列不能點進去，自動標籤列可以。
- [ ] 刪除截圖 tab 目前選中的標籤後，回到截圖 tab chip 為「全部」。
- [ ] 在詳細頁移除某張的「含電話」後，該張在「含電話」grid 消失；分類器版本更新重跑後也不會再加回。
- [ ] 最後一張帶「QR code」的截圖被移除後，「QR code」列從自動偵測區消失。
- [ ] 進入標籤 grid → 切到其他 tab → 回來時在標籤列表根畫面。
